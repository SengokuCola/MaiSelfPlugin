# 照片上的人是你吗？

作者：[SengokuCola](https://github.com/SengokuCola) · 分类：媒体处理 · [更新日志](CHANGELOG.md)

管理员上传并标注角色图片，训练“是否包含 Bot 自己”的模型。插件自动识别收到的图片和表情，在匹配图片后添加角色提示，也提供只读工具 `recognize_self_image`。

## 安装

需要 MaiBot **1.3.6+**、SDK **2.11.0+**，以及支持 `custom_pages`、`image_upload` 的 WebUI。将插件放入 `plugins/mai_recog_self`，启用后可在 WebUI 的“照片上的人是你吗？”工作区管理。

SDK 2.11.0 使用本地开发源码时，在主程序目录执行：

```powershell
$env:MAIBOT_PLUGIN_SDK_PATH = (Resolve-Path ../maibot-plugin-sdk).Path
$env:MAIBOT_WEBUI_USE_LOCAL_DASHBOARD = '1'
uv run bot.py
```

使用本地 WebUI 前，先在 `dashboard` 目录执行 `npm run build`。

插件附带通用预训练底座，角色模型需要自行训练。首次加载由宿主生成 `config.toml`，角色名通过 `character_name` 配置。

## 运行环境

默认使用 MaiBot 的 Python，插件依赖安装在自己的覆盖层 `dependencies/packages`。训练和推理优先加载覆盖层，其余包继承主环境。安装和卸载仅修改覆盖层。

自定义环境使用已有的 Python 解释器或环境目录，依赖由管理员管理。页面选择会持久保存，并优先于配置中的 `worker_python`；该配置留空时使用 MaiBot Python。更换底层 Python 大版本后需重新安装覆盖层。

GPU 版 PyTorch 默认选择 CUDA，也可选择 CPU；CPU 版使用 CPU；推理使用 CPU。训练或推理运行期间锁定依赖操作，安装期间锁定工作进程启动。

安装先在临时目录完成，再核验导入路径、版本和 CUDA 运算，成功后切换覆盖层，失败时保留原层。GPU 主包约 2.7GB，torchvision、配套依赖及解压文件需要额外空间。

下载进度、安装阶段和日志保存在插件数据目录。重载插件或重启 MaiBot 后，继续读取存活安装进程的进度，或恢复中断任务。下载支持断点续传；服务器拒绝续传或文件校验失败时重新下载，残留安装目录清理后重新安装。失败任务可手动重试。

停止推理后，通过手动开启或重新加载插件恢复。重载页面仅更新页面文件。

训练页可选择 224、320 或 448；插件配置 `input_size` 设置默认尺寸，默认为 320。设置用于新训练任务；识别和版本回退使用各模型保存的尺寸。

## 图片与标注

上传时为本批图片选择“是 Bot”或“不是 Bot”。图片库支持修改标签、跨页批量操作、删除和恢复；删除全部覆盖整个图片库。历史训练任务引用的原图会保留。

支持 JPEG、PNG 和静态 WebP。上传副本自动等比例缩放到 4000×4000 以内，超限文件转为 JPEG 压缩，透明背景补白。

- 每批最多 100 张。
- 单张原始文件上限 64MiB、1 亿像素；处理后上限 20MiB。
- 每页最多 24 张，批量操作最多 1000 张。

相同文件或像素完全一致的图片复用已有记录和标签。近重复图片按变体分组，每组保留一个训练代表。查重在上传后进行，管理员可核对排除原因和标签冲突。

## 训练与模型

每类至少需要 **20 个独立图组**。图片自动分为训练、验证和测试集。后续图片保持已有划分；同图变体跟随原组，连接不同划分的图片暂时排除。

默认增量训练：加载当前启用模型，仅训练新增或标签已修改的图片。模型保存累计训练来源，图片库显示当前模型是否训练过该图片。首次训练和从头训练使用通用预训练底座。

每个实例同时运行一个训练任务。任务开始时冻结数据和标签，训练期间的标注修改用于下一次任务。暂停保存训练状态，继续使用同一快照；最终核验阶段可取消。中断任务由管理员手动重试。

报告包含精确率及其分子分母、召回率、F1、准确率、混淆矩阵、错判图片和耗时。混淆矩阵行表示真值、列表示预测，顺序为“不是自己／是自己”。重复使用的测试集标为历史留出评测；留出标签或成员变化后，报告间的分数需要分别评估。

模型通过核验后由管理员启用，可回退上一启用版本。训练期间当前模型继续服务，版本切换前先完成加载和校验。

## 自动识别与测试

收到图片、表情和转发中的图片时，模型得分达到 0.6 会在对应图片后添加角色提示。单条消息处理预算为 6 秒，超时保留原消息。`auto_recognize=false` 可关闭自动识别。

识别测试保留最近 24 张图片及结果，可使用当前模型重新识别，显示判断、得分、版本和耗时。聊天图片与测试图片均独立于训练库。

工具接口：

```text
recognize_self_image(message_id, image_index=0)
```

工具读取当前聊天流中指定消息的图片或表情，`image_index` 为零基序号。未启用模型、消息或图片失效、索引错误及加载失败时返回具体状态。

判断门槛：得分 ≥0.6 为“是自己”，≤0.4 为“不是自己”，其余为“不确定”。得分表示模型输出，身份仍需结合上下文核对。

## 数据存储

持久数据位于 `data/plugins/maibot.mai-recog-self/`：

- `catalog.sqlite3`：图片、标签、任务和版本记录。
- `images/`：原图。
- `jobs/<任务>/`：训练快照与报告。
- `models/<版本>/weights.pt`：角色模型。
- `dependencies/packages/`：依赖覆盖层。
- `dependencies/downloads/`：下载缓存与续传文件。
- `environment-status.json`、`environment.log`：安装状态与日志。

发布插件时包含源码、页面、声明文件和通用预训练底座。运行数据、环境、配置和日志由各实例保管。

## 验证

测试命令：

```shell
python -m pytest tests
```

工具测试需要本地 SDK，CPU 流程测试需要 PyTorch。实测结果见 [VALIDATION.md](VALIDATION.md)，合成素材测试用于验证工程流程，实际识别效果由训练数据决定。

## 页面开发

共享源文件为 `webui/index.html`。修改后在插件目录执行：

```shell
uv run --no-sync python webui/build.py
```

生成页面后点击“重载页面”。修改 `webui.json` 则需要重新加载插件。
