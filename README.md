# MaiBot 自身角色识别

管理员上传正负例、人工标注并训练一个“是否包含 Bot 自己”的二分类器。默认自动识别收到的图片和表情，阳性图片后插入自身角色提示；保留只读 `recognize_self_image` 工具供显式查询。插件初始没有任何角色模型，也不读取个人图库或质量分类工程。

## 安装与本地开发

要求 MaiBot **1.3.6+**、SDK **2.11.0+**，声明式 WebUI 支持 `file_upload`。SDK 2.11.0 目前是此次改动的本地开发版本，尚未发布到 PyPI；主程序仍兼容已发布的 SDK 2.10.0，不应把整个主程序的依赖改成一个尚未发布的版本。

当前工作区开发启动方式，在主程序目录的 PowerShell 执行：

```powershell
$env:MAIBOT_PLUGIN_SDK_PATH = (Resolve-Path ../maibot-plugin-sdk).Path
$env:MAIBOT_WEBUI_USE_LOCAL_DASHBOARD = '1'
uv run bot.py
```

首次需在 `dashboard` 目录执行 `npm run build`。SDK 发布后可按正常发布版安装，不需要本地 SDK 环境变量。旧宿主/SDK 会明确拒绝不兼容插件。使用本次新版宿主和 dashboard 构建，重启主程序后启用或重载插件，在 WebUI 顶部工作区找到“自身角色识别”。

默认继承 MaiBot 当前 Python，重依赖安装到插件数据目录的 `dependencies/packages` 覆盖层。在“运行环境”页点击安装 PyTorch（CPU）或 PyTorch（GPU）即可；管理员手动触发，首次加载不会自动下载。训练与推理子进程优先使用覆盖层包，其余依赖使用底层环境。不会创建另一套 Python，也不会往 MaiBot 的 site-packages 安装、升级或卸载包。

安装使用 `uv pip install --python <底层Python> --target <插件临时目录>`，包含 PyTorch/torchvision 与匹配依赖以避免二进制不兼容。核验成功后切换覆盖层，失败保留原层。安装命令隔离外层 uv 软件源配置，并显式指定 CPU/CUDA 构建，避免 GPU 安装误拿 CPU 包。CPU/GPU版互相替换；卸载只删除该覆盖层（包含它的配套依赖），底层已有 PyTorch 仍可能可用，页面会显示实际包来源。覆盖层适用于当前底层 Python 版本，更换 Python 大版本后需要重新安装。

可选择已有的自定义 Python 环境；插件只检测和使用，不创建环境，也不安装或卸载其中的依赖。旧 `.venv` 不自动删除。`worker_python` 可以指定底层解释器；留空使用 MaiBot Python，默认同样使用覆盖层。推理始终 CPU，CUDA 训练可选。插件轻量控制层继续复用宿主已声明的 Pillow/numpy。

配置热更新会立即更新角色显示名；`worker_python` 对之后启动的进程生效，正在训练或提供推理的进程继续使用原环境。需要立即更换常驻推理环境时，在训练结束后重新加载插件。

“运行环境”页面的选择会持久保存，并优先于 `worker_python`。默认使用共享覆盖层；自定义环境填写已有 Python 解释器或环境目录的绝对路径，插件只检测和使用，不创建环境或安装依赖。旧独立环境保留原解释器路径，按只读自定义环境使用。

默认配置包含宿主要求的 `[plugin]` 节：`enabled = true`、`config_version = "0.1.0"`。首次加载由宿主生成 `config.toml`，无需手工创建。

`assets/mobilenet_v3_small-047dcff4.pth` 是 ImageNet 底座，SHA256 为 `047dcff4addef86ea5bc2eff13c9614dc11f47ab1160d0a71a25e7db994f4e1f`；源地址：<https://download.pytorch.org/models/mobilenet_v3_small-047dcff4.pth>。没有附带已训练的麦麦模型。模型约 152 万参数（0.00152B），MobileNetV3-Small 卷积视觉网络与二分类头；无需 LLM、教师 API 或图片描述。

## 使用

1. 在插件配置设置 `character_name`，上传 JPEG、PNG 或静态 WebP。网页逐张检查尺寸；宽或高超过4000时等比例缩到4000×4000以内并转JPEG，文件超过20MiB但尺寸正常时保持尺寸转JPEG压缩。透明背景转JPEG时补白；只处理上传副本，不改本地原图。处理后的文件不超过20MiB。支持多文件进度，每批最多100张、原图总量128MiB，单张原图最多64MiB和1亿像素；不接受动画或压缩包。
2. 点击“上传图片”按钮，在同一弹窗内选择图片文件及本批身份“是Bot／不是Bot”，确认后点击“开始上传”，新图片入库时直接带标签；重复上传复用已有记录，不覆盖原标签。紧凑卡片下直接改标“是自己／不是自己”或删除，不提供跳过。勾选卡片可跨页批量标注或删除，支持全选本页、取消本页和清空选择，每批最多1000张；成功执行批量操作后清空选择，失败保留选择。删除全部覆盖全部页面和筛选之外的图片，确认后执行。桌面每行4张，每页最多24张，预览最高512像素，生成后缓存；标注刷新不会重新解码原图。删除从默认列表与训练库移出，可在“已删除”视图恢复；保留历史任务所引用的原图及已训练模型。卡片保留图片ID和图组/划分信息供核对。

重复上传相同文件，或解码后像素完全一致的图片，会返回已有记录，不重复保存，不覆盖原标注。当前查重发生在服务器收到图片之后，因此仍会传输文件；裁剪、缩放等近重复变体保留核对记录，并按图组只选一个代表训练。
3. 每类至少 20 个独立图组，首次按组划分 70%/15%/15%，seed42，各划分每类至少两张。同作者不是隔离条件。新增图保持既有划分；变体跟随原组；连接不同划分的图片暂不训练。近重复规则为 DCT pHash 汉明距离 ≤4 且对数宽高比差 <0.12，或完全相同的解码哈希。请人工核对排除结果。
4. 训练任务默认 CPU、增量。首次没有启用模型自动从头；以后增量加载当前启用版本并回放全部可用旧训练图。勾选从头则重新从 ImageNet 初始化，不继承角色权重。任务立即返回，训练和环境页面可见时每 5 秒轮询，后台标签暂停轮询；每个实例最多一个训练任务。点击开始训练自动管理内部幂等编号，网络重放返回同一任务；终态后的下一次点击创建新请求，不再手工填写编号。提供暂停、继续、取消；暂停保存模型、优化器、当前批次顺序和随机状态后退出子进程，继续沿用原快照和任务。最终测试核验阶段只允许取消，不再暂停。不会自动重试训练。
5. 直接点击任务卡片的“查看报告”或“查看错判”；错判页可返回全部图片，不再填写任务ID。报告展示 precision 的分子分母、recall、F1、accuracy、混淆矩阵、选择轮次、核验与实际时间。混淆矩阵行是真值、列是预测，顺序为“不是自己／是自己”。测试集重复使用时为历史留出评测；留出真值或成员改变，标记与旧报告不可直接比较。
6. 核验通过的版本在“模型版本”手动启用；加载及 SHA 校验成功后才原子切换。旧模型在训练期间继续服务。可回退前一个启用版本，回退也会校验并更新推理缓存。
7. “识别测试”弹窗先选择并预览图片，再点击“开始识别”。文件传输成功但识别失败时显示失败，可重试；进程退出与响应超时分别报告，退出附带本次推理日志。结果以图片卡片显示判断、得分、版本和耗时，最多保留24条最近结果；图片不进入训练库。测试使用同一 CPU 推理入口；LLM 通过真实消息 ID 识别图片，`image_index` 为同一消息图片与表情合并后的零基序号，不接受路径或 URL。

工具三态门槛：得分 ≥0.6 为“是自己”，≤0.4 为“不是自己”，中间“不确定”。得分不是校准后的正确概率。未启用模型、跨聊天/不存在消息、无图片、图片失效、索引错误及加载失败都会返回具体状态。

## 训练与数据

持久目录为 SDK 分配的 `data/plugins/maibot.mai-recog-self/`，包含 `catalog.sqlite3`、`images/`、`jobs/<任务>/snapshot.json`、报告及 `models/<版本>/weights.pt`。不要把这些运行数据放入插件仓库。训练期间标注变更只影响下一次任务，原快照与报告保持不变。原图与标注不因任务取消或失败被删除。

整图保持比例，补边到 320×320，不切片。默认 CPU batch8、最多4线程；CUDA batch32。类别加权交叉熵、AdamW、weight decay1e-4、轻度颜色增强。首次最多15轮，前3轮只训练分类头（1e-3），之后最后4个视觉模块（1e-4）及分类头（3e-4）。增量最多10轮，视觉3e-5、头1e-4，重建优化器。

按验证 F1、balanced accuracy、precision、较早轮依次选择；二分类门槛固定0.5。选轮记录和 SHA 保存后才打开测试。发布前检查有限权重、实际改变、训练全量回放、分组/ID/哈希隔离、输入哈希、验证与测试指标重算、保存后 CPU 重载及输出一致性。选中头部预热轮可能尚未更新视觉层，这是允许的验证选择结果。

训练与推理在两个独立子进程。取消、卸载、意外退出有明确状态；控制器重启会将未完成任务标为 interrupted 并请求旧进程退出，绝不自动重启。训练进程监测租约，控制器失效后停止；旧进程未退出时禁止新训练。

## 验证

在插件环境执行 `python -m pytest tests/test_catalog.py tests/test_worker_lifecycle.py tests/test_cpu_acceptance.py`；工具测试在包含本地 SDK 的宿主测试环境执行。完整 CPU 验收测试包含从头15轮、增量10轮、保存重载、启用、缓存刷新、回退及损坏模型拒绝；合成图片只验证工程流程，不代表身份识别效果。实测与限制见 [VALIDATION.md](VALIDATION.md)。

不支持普通聊天用户训练、多人角色平台、自动启用或自动收集聊天图片。管理员应提供足够丰富且身份明确的正负例，并独立检查新图片表现。

## 环境管理与自动识别

“运行环境”页后台检测实际 Python、依赖来源、PyTorch、torchvision 与 CUDA 张量运算，显示安装日志与覆盖层路径。可选择共享覆盖层或已有自定义环境，选择持久保存。自定义环境隐藏依赖安装按钮与安装日志，后台也禁止安装或卸载；依赖由管理员在该环境中自行管理。训练或推理占用环境时拒绝更换依赖，可先停止推理；安装过程中禁止启动新工作进程。安装结束核验实际加载路径、版本和真实 CUDA 运算，卸载从不删除底层包。此功能不增加主程序依赖。

点击“停止推理”后，本次插件运行期间保持关闭；收到图片、工具调用或页面测试不会自动启动，也不会使用缓存添加身份提示。通过“开启推理”手动加载当前模型，或重新加载插件后恢复识别。重载页面只更新 HTML，不恢复推理。

GPU 主包下载约 2.7GB，另有 torchvision 和其他依赖；解压和新旧覆盖层并存需要额外磁盘空间。运行环境页显示当前安装包的实际已下载字节、总量和百分比，安装及核验阶段显示阶段进度。状态保存在数据目录的 `environment-status.json`，日志在 `environment.log`，缓存安装包和可续传文件在 `dependencies/downloads`。

重载插件或重启 MaiBot 时，仍存活的独立安装进程继续运行，页面恢复读取原进度；已经退出的未完成安装会自动恢复。支持 HTTP Range 的服务器按 `.part` 文件长度续传，不支持续传或 SHA256 不符则清理该文件重新下载；完整包通过官方 SHA256 核验后复用。残留的半安装目录清理后重新安装，上一覆盖层在新环境核验通过前保留。若上次安装子进程还活着，先等它退出，不重复安装。显式失败不自动无限重试，修改环境后也不自动向新环境安装。首次安装仍由管理员手动触发。

自动识别复用既有 `chat.receive.before_process` 阻塞钩子，不新增宿主专用角色逻辑。读取消息中的图片/表情（包括转发内容），只在得分≥0.6时紧跟对应图片插入文本提示；不确定或阴性不插入。单条消息总预算6秒，超时保留原消息。缓存按图片SHA、启用模型版本与角色名区分，最多512项。配置 `auto_recognize=false` 可关闭；聊天图片不入库、不打身份标签。结果提示是模型判断，不能当作确认身份。

页面要求宿主能力 `custom_pages` 和 `file_upload`，须同时使用本次主程序与前端构建。Python SDK没有单独的组件渲染器，SDK上传领取与消息钩子仍复用现有接口。

WebUI 使用单文件自定义工作台，提供图片标注、训练任务、模型版本、识别测试、运行环境五个宿主侧边入口，使用宿主公共组件样式，跟随原版、未来复古、千禧风格与明暗主题切换，支持窄屏，内容随宿主页面滚动，标题由宿主统一显示。上传复用宿主已有接口和受控桥接。上传可取消并重试失败或未发送文件；关闭弹窗会取消未完成上传，已接收文件保留。报告与错判在当前页面中查看，可返回原功能页；切换侧边入口或刷新页面会重置当前详情。不可用操作保留按钮并显示原因，后台轮询不阻塞点击。

运行环境页面按“状态概览 → 当前路径与版本 → 环境操作 → 任务与日志”分区。日志使用可滚动的只读内凹框，详细失败内容保留在日志内；模式切换和停止推理使用各自准确的确认说明。

WebUI 共享源文件为 `webui/index.html`，修改后执行 `uv run --no-sync python webui/build.py`（在插件目录下）生成五个页面，再重载插件。无需重新构建主程序前端。
